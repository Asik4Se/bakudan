# BAKUDAN — 爆弾回し

複数人で爆弾を時計回りに回していき、爆発したときに持っていた人が脱落。最後に残った1人が勝ちのオンラインゲーム。

## ルール

- 爆弾は**時計回り**に回る
- 爆発までの時間は **30〜60秒** でランダム。カウントダウンが見えるのは **最初の5秒だけ**。あとは全員頭の中で数える
- 爆弾を持てるのは **最大5秒**。残り時間は数字ではなく **ゲージ** で表示。ゲージが切れると自動で次の人へ回る
- 爆発したとき持っていた人が脱落。生存者が **5人以上** のときは、**ひとつ前の手番の人**（直前に持っていた人）も爆風で脱落
- 最後の1人が勝ち

## 人数・NPC

- 最大 18 人、最低 4 人
- 人間が 3 人以下なら、4 人になるまで NPC が自動で参加
- ホストはロビーで NPC を自由に増減できる（合計 18 人まで、4 人未満にはできない）
- 開始前に「観戦」を選べる。ゲーム中に来た人は観戦になり、次のゲームから参加
- ゲーム中に切断したプレイヤーは NPC が代打。同じブラウザで開き直すと復帰

## 操作

- 「回す」ボタン / 爆弾をタップ / スペース・Enter キー
- 受け取ってから 0.3 秒は回せない（連打防止）

## ローカルで動かす

```bash
npm start
# http://localhost:3000
```

依存パッケージはありません（Node.js 18 以上）。

## Render へのデプロイ

New → Web Service でこのリポジトリを選び、

| 項目 | 値 |
| --- | --- |
| Runtime | Node |
| Build Command | `npm install` |
| Start Command | `npm start` |
| Health Check Path | `/healthz`（任意） |

ポートは Render の `PORT` 環境変数を自動で使います。

## 調整用の定数

`server.js` の先頭にまとまっています（最大人数、持てる時間、爆発までの時間の範囲、爆風が起きる人数など）。
